## 4. Dependabot (сангийн шинэчлэл)

- **Жижиг шинэчлэл (minor, patch):** CI ногоон бол **өөрөө нэгтгэгдэнэ** (`dependabot-automerge.yml`). Юу ч хийх хэрэггүй.
  Нэг удаа тохируулах: Settings → General → **Allow auto-merge**-ийг асаах.
- **Том шинэчлэл (major, жишээ нь `undici 7 → 8`):** өөрөө нэгтгэгдэхгүй.
  - CI ногоон, аюулгүй байдлын засвар биш бол: хүлээлгэж болно, сайтад хор хүргэхгүй.
  - CI ногоон, «security» гэсэн бол: **Merge** дар. Дараа нь сайтыг нээж хэвийн эсэхийг хар. Эвдэрвэл PR дээрх **Revert** товч.
  - CI улаан бол: бүү нэгтгэ. §5-ын дагуу Copilot-оос засуулах эсвэл PR-ийг хаах.

## 5. Код засах шаардлагатай бол: `@gemini` (үнэгүй)

### 5.1 `@gemini`

Issue дээр **`@gemini`** гэж эхэлсэн сэтгэгдэл бичихэд Google-ийн Gemini CLI репог
уншиж, кодыг засаж, `npm run check` ажиллуулаад PR нээнэ (`.github/workflows/gemini.yml`).
Google-ийн үнэгүй эрхээр ажиллана. Зөвхөн та болон collaborator-ууд ажиллуулж чадна; гадны хүн
бичсэн `@gemini` юу ч хийхгүй.

Нэг удаа тохируулах (үнэгүй):
1. https://aistudio.google.com → **Get API key** → **Create API key** → **шинэ project** үүсгэ.
   Тэр project-д **billing (карт) бүү холбо**: тэгвэл үнэгүй хэвээр, хязгаар хэтэрвэл зүгээр л зогсоно.
   Pipeline-ийн `GEMINI_API_KEY`-г бүү ашигла: тэр project төлбөртэй.
2. Репо → Settings → Secrets and variables → Actions → **New repository secret** →
   нэр `GEMINI_AGENT_API_KEY`, утга нь 1-р алхмын түлхүүр. Түлхүүрийг чат эсвэл issue-д хэзээ ч бүү бич.

Хэрэглэх:
1. Watchdog issue дээр (эсвэл шинэ issue нээгээд) ингэж бич:
   > @gemini энэ issue-ийн асуудлыг засаад PR нээ
2. Gemini «ажиллаж эхэллээ» гэж бичээд 5–30 минутын дараа PR-ийн холбоосыг issue дээр бичнэ.
   Код өөрчлөх шаардлагагүй (жишээ нь токен, төлбөр) гэж үзвэл тайлбар бичээд юу ч өөрчлөхгүй.
3. PR-ийн доор **check, mobile-layout** бүгд ✅ болмогц **Squash and merge**.
   ❌ бол тэр PR-ийг хаагаад **issue дээрээ** «@gemini өмнөх засварын CI унасан: <алдааны мөр>. Дахин засаарай» гэж бич.
   (PR дээр бичсэн `@gemini` ажиллахгүй: аюулгүй байдлын үүднээс Gemini зөвхөн issue-ээс, `main` дээрээс ажилладаг.)
4. Vercel 2–3 минутын дараа шинэ хувилбарыг гаргана. Эвдэрвэл PR дээрх **Revert**.

Анхаар: Gemini-ийн үнэгүй эрх өдрийн хязгаартай. «ажиллаж чадсангүй» гэвэл маргааш дахин бич.
`.github/workflows` доторх файлыг Gemini засаж чадахгүй (GitHub зөвшөөрдөггүй).

### 5.2 GitHub Copilot агент (Copilot Pro $10/сар авбал)

Copilot Free (VS Code-ийн chat, нөхөлт) агент горимгүй; issue-г Copilot-д оноож PR нээлгэх нь
Copilot Pro ба түүнээс дээш багцад л байдаг. `.github/copilot-instructions.md` агентад
төслийн дүрмийг автоматаар өгнө.

1. Watchdog issue-ээс засах мөрийг хуул.
2. github.com → **Agent** (эсвэл issue дээр **Assign to Copilot**) → репо `tmorius-eng/UNENMEDEE`.
3. Ингэж бич:
   > CLAUDE.md-г бүтэн уншаад дараах асуудлыг зас: «<issue-ийн мөр>». `npm run check` ногоон байх ёстой. Засварыг жижиг байлга, тест сулруулж болохгүй. PR нээ.
4. Агент PR нээнэ. PR-ийн доор **check, mobile-layout** бүгд ✅ ногоон болохыг хүлээ.
5. Бүгд ногоон бол **Squash and merge**. Улаан бол бүү нэгтгэ, агентад «CI улаан байна, логийг уншаад зас» гэж PR дээр бич.
6. Vercel 2–3 минутын дараа шинэ хувилбарыг гаргана. Эвдэрвэл PR дээрх **Revert** эсвэл §2-ын Vercel буцаалт.

Ямар ч AI чатад (Copilot, ChatGPT, Claude) нууц түлхүүр, нууц үг, `DATABASE_URL`-ийг **хэзээ ч бүү хуул**.
Тэдгээр нь зөвхөн GitHub Secrets болон Vercel-ийн тохиргоонд байна.
