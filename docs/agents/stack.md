## 2. Tech Stack
- **Framework:** Next.js 16 (App Router, Turbopack, React 19.3, Server Actions), TypeScript strict mode.
  - `cacheComponents: true` and `partialPrefetching: true` are ON. Cache DB reads with `'use cache'` + `cacheLife(...)` + `cacheTag(...)` (see `src/lib/queries`). Lifetimes: the custom `news` profile (`next.config.ts`, revalidate 30 min) for feeds, digests, search and the news sitemap, `hours` or longer for everything else; never the built-in `minutes`: a page revalidates as often as its shortest entry, and the header's `minutes` stats re-rendered every visited page once a minute (Nov 2026: 306 K ISR writes against Hobby's 200 K, Active CPU 2 h 50 min of 4 h). Nothing hourly belongs in the root layout either: with the header's `hours` stats every page (~3 000 articles) revalidated hourly on crawler visits (419 K ISR writes by Nov 6 2026), so the header's live line is fetched by the browser from `/api/pulse` (`live-status.tsx`, one cached response), and article pages, their topic-neighbour list, clusters and archive days switch to `days` once settled (`SETTLED_AFTER_DAYS` 8 / two days back, `isSettled` in queries.ts; `cacheLife` in `if`/`else` branches, its overloads refuse a union). Anything reading `cookies()`, `headers()`, `searchParams` or `params` must sit inside `<Suspense>`.
  - Supabase egress (free 5 GB/month; Nov 2026: 6.2 GB by day 19, the project faced restriction): a query returns only what the page shows. List rows (`listColumns`) carry the neutrality score, `amounts_mnt` and a "has deep analysis" flag computed in SQL, never `fact_vs_spin` / `extracted_entities` / `grok_deep_analysis` (only `getArticleBySlug` selects those); a big `indicator_snapshots` row is sliced in SQL (`getOfficialCompanies` reads one member's companies, not the 57 KB snapshot); filters belong in the `where`, not in JavaScript after a 1 000-row read (`getNewsSitemapArticles`); data that changes daily or slower (officials, company tenders) uses `cacheLife("days")`. Check `extensions.pg_stat_statements` (reset with the billing cycle) for calls × rows before adding a query that runs on every render.
  - Instant refresh after writes: the pipeline's last step (and `maintenance.yml` reanalyse / recluster / refetch-dates) runs `npm run cache:purge` (`scripts/purge-cache.ts`), which stores a one-use 64-hex nonce in `app_settings.revalidate_nonce` and POSTs it to `/api/revalidate`; the route deletes the nonce with a conditional `DELETE … RETURNING` (single use, 5 min, `src/lib/cache-purge.ts`) and calls `revalidateTag(tag, { expire: 0 })` (the next request renders fresh; `"max"` would still serve the old page once) for `feed`, `digests`, `clusters` (`--all` adds `articles`, ~3 000 article pages, so only after a repair). No new secret: both sides already reach the database. The `feed` tag is only on the pages a new story changes at once: home/topic feeds (`getFeed`), place feeds, the archive day list and the laws list. Never on per-day archive pages or source hubs: purging them every run re-rendered hundreds of pages each half hour, and the Vercel Hobby project was paused on Nov 8 2026 (402 `DEPLOYMENT_DISABLED`, the monthly ISR/CPU limit already over). A failed purge only warns: the `news` lifetime still refreshes the pages.
  - Dynamic routes must return at least one entry from `generateStaticParams` (we use a placeholder and `notFound()` it). The page component checks its param and the cached lookup and calls `notFound()` **before** any `<Suspense>` (article, clusters, officials, archive, source, place, topic, promises, projects): inside Suspense the 200 was already sent and every missing URL stayed a soft 404 (200 + noindex) in the CDN. With `partialPrefetching` the very first request to an unseen URL still streams the shared shell (200 + noindex); the entry it stores, and every later request, is a real 404.
  - Route guarding uses `src/proxy.ts` (Next 16 renamed `middleware.ts` to `proxy.ts`).
  - Lint with `eslint .` (`next lint` no longer exists).
- **Design system (mandatory):**
  - **Visual direction «Тунгалаг дэвтэр» (Ledger, Oct 2026):** the page is one surface (`bg-primary` `#fbfbf9` / `#0f1012`; panels `bg-secondary`), separated by 1 px hairlines (`border-line`, `border-line-soft`, `ring-line`), never floating cards (`--shadow-xs/sm` are none; only menus and sheets have shadows; radius 2xl = 10 px, 3xl = 12 px). Brand is the logo's teal (`--color-brand-*` oklch scale, 600 = `#047c78`, `text-brand-secondary` = 700 light / 300 dark for 4.5:1); `signal` (yellow `#ffd400` / `#ffd166`, always `signal-ink` on it) marks the lead rule, ₮ chips and key numbers; `risk` / `risk-soft` for the risk chips. Headlines use `headline` / `.story-headline` (Inter Display, weight 750, −0.03em, `text-wrap: balance`), numbers `num-mono`, small labels `label-mono` (JetBrains Mono, uppercase, 11 px). Semantic tokens are `light-dark()` pairs in `theme.css`: a mode is only a `color-scheme` switch (`.light-mode` / `.dark-mode` from next-themes); the inverted `utility-*` hue scales are the only `.dark-mode` overrides left. `THEME_COLOR` in `site.ts` (viewport, manifest) must match `--color-bg-primary` / `--color-brand-600`. The faint paper grain (`grain`) is for the masthead only.
  - **Untitled UI React** (https://www.untitledui.com/react) is the primary component library: React Aria Components + Tailwind CSS v4. Theme tokens live in `src/styles/theme.css`; the vendored base components left are `src/components/base/{badges,buttons}` and `foundations/dot-icon.tsx` (the rest was unused and removed in Oct 2026; vendor a component again only when a page needs it). Merge classes with `cx()` from `src/utils/cx.ts`.
  - **ElevenLabs UI** (https://ui.elevenlabs.io) for conversational/AI surfaces: `Message`, `MessageContent`, `MessageAvatar`, `Response`, `Conversation`, `ShimmeringText` (the three.js `Orb` was removed: unused, heavy). Installed with the shadcn CLI (`components.json`, e.g. `npx shadcn@latest add https://ui.elevenlabs.io/r/message.json`) into `src/components/ui/`. Every AI-generated text block (TL;DR, deep analysis, cluster synthesis, admin filter chat) renders through `Message` (+ `Response` for Markdown) (see `src/components/iltod/ai-message.tsx`).
  - The vendored ElevenLabs files were **adapted to Untitled UI tokens** (Untitled's `bg-primary` is the page background, not shadcn's brand color). `avatar.tsx` / `button.tsx` are local, dependency-free shims and `cn()` lives in `src/lib/utils.ts`. `response.tsx` passes `controls={{ image: false }}` (the image download control's fallback opened a new tab with `window.opener`). Re-running `shadcn add` overwrites these edits: re-apply them, and never let it add the unrelated `cn` npm package.
  - Chart colors: `src/styles/charts.css` (validated categorical slots; every chart has a table view).
  - Animation: CSS first (`panel-enter` = `@starting-style`, `reading-progress` = scroll-driven, React 19.3 `<ViewTransition name="hl-<slug>">` morphs a story headline from the list into the article `<h1>`, no Next config needed). Feedback on a completed action may use a short keyframe: `check-pop` (the ✓ on a tap, set from state so restored rows never pop on load) and `flame-pop` (the digest streak's 🔥 once the edition is finished); `scroll-shadow-host` / `scroll-shadow` give the sticky header a soft shadow once it is stuck (`@container scroll-state(stuck: top)`, Chrome 133+; others keep the hairline). Story headlines underline in brand on mouse hover. All of it respects `prefers-reduced-motion`. The `motion` package stays only for `ui/shimmering-text.tsx` (admin); `fact-spin-panel.tsx` is CSS-only (radio inputs + `group-has-[input[value=spin]:checked]`), so no public page ships `motion`.
  - Charts: `recharts`. Icons: `@untitledui/icons` (prefer). `lucide-react` is not installed: the few Lucide marks Untitled lacks (pickaxe, sprout, landmark…) are vendored as paths with the ISC notice in `src/components/iltod/topic-icon.tsx`.
- **Database:** Supabase PostgreSQL with `pgvector`, managed via **Drizzle ORM** (`drizzle-orm` + `pg` node-postgres pool, `drizzle-kit`). Never use postgres.js for app queries: its pipelining hangs behind the Supabase transaction pooler (only `scripts/migrate.ts` uses it, sequentially). Schema: `src/db/schema.ts`. Migrations: `drizzle/`. TLS to the database is verified (`src/db/tls.ts`, Oct 2026 security scan; it used to be `rejectUnauthorized: false` / postgres.js "require", which accept any certificate): `databaseTls()` passes Supabase's public root CA (`src/db/supabase-ca.ts`, also `certs/supabase-root-2021-ca.pem` so the watchdog dates it; valid to 2031-04) with the host name checked, `DATABASE_SSL_CA` adds a root for a database elsewhere, and `withoutSslParams` strips `ssl*` parameters from `DATABASE_URL` (node-postgres lets `?sslmode=…` replace the `ssl` option, `no-verify` included). `getDb`, `scripts/migrate.ts` and `drizzle.config.ts` (structured credentials: drizzle-kit drops an `ssl` next to `url`) all use it. After a database or TLS change run the manual `maintenance.yml` task `db-check` (`npm run db:check` + `db:migrate`, prints the server's certificate chain).
- **Scraping Engine:** Node.js scripts in `/scripts` using `crawlee`, `cheerio`, `@mozilla/readability`, `jsdom`. Library code in `src/lib/scraper`.
- **AI SDK:** `openai` package with custom `baseURL` for Groq, Mistral, Requesty, NVIDIA NIM, OpenRouter, Z.ai, DeepSeek, xAI Grok and Ollama; Gemini uses its native `generateContent` API via `fetch` (`src/lib/ai/gemini.ts`). Library code in `src/lib/ai`.
- **Admin Editor:** Tiptap (`@tiptap/react`, `@tiptap/starter-kit`).
