## 3. Target Data Sources (Phased Approach)
- **Tier 1 (Structured & High-Value):** `opendata.gov.mn` (HTML scraping of dataset listings, no CKAN API), `tender.gov.mn` (procurement invitations & results), `legalinfo.mn` (new resolutions).
- **Ulaanbaatar:** `ulaanbaatar.mn` (times out from outside Mongolia, kept), `niislel.khural.mn`, and the districts on their own domains: `khanuul.mn`, `shd.ub.gov.mn` (http), `bgd.mn` (JavaScript app, browser pass), `sbd.gov.mn`, `chingeltei.gov.mn`, `nad.ub.gov.mn`, `bnd.ub.gov.mn`, `bagakhangai.ub.gov.mn`. `bzd.ub.gov.mn` (Баянзүрх) is a suspended hosting page (Oct 2026): re-check before seeding. District slugs are in `AIMAG_SLUGS` so discovery files them as `local`.
- **Tier 2 (Ministries & Agencies):** `zasag.mn`, `mof.gov.mn` (Finance), `mojha.gov.mn` (Justice), `mmhi.gov.mn` (Mining), `med.gov.mn` (Economy), `mfa.gov.mn` (Foreign Affairs), `moh.gov.mn` (Health), `met.gov.mn` (Environment), `iaac.mn` (Anti-Corruption), `audit.mn` (National Audit), plus the remaining ministries seeded in `scripts/seed-sources.ts`.

### Scraper architecture (`src/lib/scraper`)
- `adapters/index.ts`: sources with a public API or feed skip HTML crawling: opendata.gov.mn, parliament.mn, zasag.mn (= `mongolia.gov.mn/feed` RSS with full HTML; zasag.mn's own cert and /news are broken, links are rewritten to mongolia.gov.mn) and legalinfo.mn (new legal acts via `POST /mn/ajaxLlist/`, text from the detail page's `.maincontenter`; `ScrapedItem.loadText` fetches details only for unseen URLs) and police.gov.mn (`/a/?page=1&size=20` cards → `/a/{id}`; the list has only the image-path day, `loadText` returns the text plus the exact time; image-only posts have no text and are skipped); the www.gov.mn portal (`adapters/govmn.ts`, Nov 2026): every government body has a news page there (`/news?organizationSlug=<slug>`, stories `/news/n/<code>`), and bodies whose own site fails post there the same day (mof.gov.mn and customs.gov.mn time out from outside Mongolia, mojha/bulgan 404, culture.gov.mn under maintenance, tov.gov.mn a 2021 shell, 11 aimag governors' offices…; a second pass the same day mapped 18 more whose own site gave 0–3 published stories in 30 days while the portal had more, among them afccp.gov.mn = the competition authority's "Монополын эсрэг газар" page, gadpwd.gov.mn (domain gone) and bzd.ub.gov.mn (suspended), and reactivated dundgovi/orkhon/bzd/gadpwd; President's Office: president.mn is a Cloudflare challenge and is not on the portal, so it stays failing); `GOVMN_ORGS` maps our source domain to its slug, the list comes from the portal's own `/api/routes/news` JSON (Ulaanbaatar times), the text from the story page's React Server Components payload (`news.content`, a long one a separate `T` row whose length counts UTF-8 bytes), photo posts are skipped, the source re-check reads the same payload; all of it is one host, so API sources together get at most `API_BUDGET_SHARE` (35 %) of `--budget` in run-scraper.ts and the rest wait their turn (`completed: false`); API sources run one queue per host side by side (`groupByApiHost`, `apiHost` in `adapters/index.ts`), because one serial loop let the portal's backlog (8 s a story) leave police.gov.mn, parliament.mn, zasag.mn and legalinfo.mn "not reached" (Nov 4 2026); and nhrcm.gov.mn (`adapters/nhrcm.ts`: an Angular app with hash-route links the crawler drops; `POST /back/api/content/list` menu 7 returns full HTML and the day). Not reachable on purpose: frc.mn checks the visitor's country and shows nothing abroad, chinggiskhaanswf.mn's robots.txt carries content signals (`ai-train=no, use=reference`), conscourt.gov.mn and bzd.ub.gov.mn are suspended hosting pages.
- tender.gov.mn and shilendans.gov.mn are `is_active = false` (Cloudflare 403 / no news). Do not try to get around Cloudflare; shilendans' JSON API (`back.shilendans.gov.mn/proxy/`) is a future budget-data source, not news.
- `--days <n>` backfill: WordPress REST `after=`, feed dates, and only items with a known publication date inside the window (undated items would be stored as "today").
- Titles (`titles.ts`): `chooseTitle` takes the first non-generic of Readability → `og:title` → first `<h1>` → `<title>`; `isGenericTitle` rejects section words ("Мэдээ", "Нүүр хуудас"), the site's own name or abbreviation ("Мэдээ | ТТХГ") and < 8 characters; the fallback is `firstSentenceTitle` (skips date lines). `unshoutTitle` (db-sink and the demo seed) turns ALL-CAPS headlines into sentence case, keeping abbreviations (`ACRONYMS`), initials ("Х.Баттулга") and common proper nouns; a hashtag's underscores count as word breaks and stay ("#Хамтын_сэтгэл_халуун"). `db-sink` also treats a title this source already used in the last 30 days as the site's title (opendata excluded); a site title over glued menu text (`looksLikeNavigation`) is a homepage/menu page and is stored with `is_published=false`; so is a help page whose headline ends in "асуулт хариулт" or starts with "Түгээмэл асуулт" (`looksLikeUnitPage`, crc.gov.mn's FAQ pages; `db:repair-dates` step 6 applies it to stored rows).
- Dates: `extractPublishedDate` checks meta tags, JSON-LD, the page's data blob (`jsonBlobDate`: `__NEXT_DATA__` / `__NUXT__` / `application/json` scripts with a `createdDate`/`date`/`publishedAt` key; mofa.gov.mn prints no date in its markup), `<time>`, the URL, then the headline area (date-ish class or a calendar icon between the headline and the body start, so "related news" dates below are ignored; anchored on the `<h1>` or the element holding the headline), a stamp next to a clock/calendar icon in the headline's own container (`iconStampDate`, uvurkhangai.gov.mn prints it under the body; trusted even when old, so old stories get their real date and stay off the feed; when the icon's line holds more fields, khural.mn's "Огноо: 2025-07-29 · Дугаар: 06/01 · Нээгдсэн: 218", only the text right after the icon is read), then the text. `og:article:published_time` (mcud.gov.mn) counts as a meta date. Times are Ulaanbaatar (UTC+8). Undated items keep `published_at` = found time (feeds sort by it) but get `scrape_meta.date_unknown` ("Огноо тодорхойгүй" on the page, left out of the Google News sitemap), and an undated text whose newest year is before last year (`looksOld`) is stored unpublished. `npm run db:fix-titles` (`--dry-run`, `--dates`) repaired the rows stored before this.
- `src/lib/opendata-mn`: opendata.mn datasets via the portal's documented API (`/apiv1/file/{id}`, the URL its "API харах" button gives out). Its robots.txt disallows `/apiv1/` for crawlers; we skip the robots check for these documented API URLs only, keep the 8 s host delay, and sync at most twice a day. Only metadata and small computed highlights are stored (`open_datasets`), never raw rows.
- Source re-check (`recheck.ts`, `npm run sources:recheck`, weekly `source-recheck.yml`; a manual run is a dry run unless `dry_run=false`): the last 30 days of articles are fetched again with the same text getter (extractArticleSafe / police / legalinfo; opendata, parliament and zasag are skipped, as are admin-edited and pruned rows). Never compare hashes (widgets change). Lines we add when storing (legalinfo's "Батлагдсан байгууллага:") are skipped (`OUR_PREFIX`). `compareTexts` counts our stored sentences still on the page: below `CHANGED_BELOW` (0.8) or a changed number → `source_status='changed'` + `source_diff` (≤ 12 before/after or removed sentences); 404/410 or a redirect away on `GONE_CHECKS` (2) checks ≥ 6 days apart → `gone`; errors and failed extraction are skipped, and so is a re-read matching under `UNREADABLE_BELOW` (0.2) of our sentences (the getter read another block). Page furniture never counts (`isChrome`: e-mail lines, lines ≥ 80 % capitals; `COUNTER` also reads "санал өгсөн: 11283"), containment ignores spacing (`compact`), text after a related-news heading ("Бусад мэдээлэл", "Шинэ мэдээ": `RELATED_HEADING`) is the sidebar and is not compared, and a page read (body included) never throws, so one slow site cannot end the run: in Nov 2026 a poll's vote count, a footer and "уу.ШҮҮГЧИЙН" vs "уу. ШҮҮГЧИЙН" marked 7 stories as changed by the government. The article page shows `SourceChangeNotice`, `/changes` lists them, and `/method#recheck` explains it. Wording stays neutral (a change can be a correction).
- `crawl.ts`: one Crawlee run for all other sources. Pass 1 = HTTP (WordPress REST API → RSS → link harvesting, homepage fallback). Pass 2 = headless Chromium (Playwright) only for sources whose news needs JavaScript.
  - WordPress: the REST base comes from `<link rel="https://api.w.org/">` (`wordPressApiBase`, handles `?rest_route=`); posts without `link` are reached as `/?p=<id>`; when the REST call fails or is empty the feed is tried, then the harvested links. Links (`links.ts`): an article id in the query string (`/?p=123`, `mn.php?page=40&news=1633`, `QUERY_ID`) counts, bare pagination (`?page=2`) does not; `[href]` on any element is harvested; `sameSite` never treats the parent domain (`gov.mn`) as the same site. A listing with < 3 article links is a splash page: `harvestSectionLinks` follows up to 3 news sections (`/home`, `/j`, `/c/medee…`, anchors reading "Мэдээ") one hop, once per pass (`pendingSections`). 404/410/451 pages are errors, and a listing reached with nothing stored and nothing known is a failure ("listing reached but no articles were stored"), so backoff works.
  - Dates: `parseDateValue` reads meta/JSON-LD/`<time>` values; no zone = Ulaanbaatar (+08:00). A `<time>` > 1 year older than the newest one on the page is a stray stamp (judcouncil.mn's 2019); a date printed in the text is only trusted when < 1 year old (mrpam's 2009 resolutions). "11-р сар" is November (`MONTH_LABEL`, lookbehind); iaac.mn prints "10 сарын 20, 2026" (month and day first, the year after a comma). `normalizeText` also strips the invisible Hangul/Braille fillers (U+3164 …) editors paste as a blank first line.
  - db-sink: `publishDecision` (`dates.ts`): dated items older than `MAX_AGE_DAYS` (60; a `--days` backfill widens it) are stored `is_published=false`; an undated text that names no year at all or whose newest year is before last year (`isTimelessPage`: department pages, instructions, a 2020–2024 programme) is stored unpublished too, and `NON_ARTICLE` skips `/p/<id>`, `/home`, `/posts`, `/instructions`, `page.aspx` paths (db-sink also stores CMS static pages `/page/<slug>`, `/pages/<id>`, `/p/<id>` unpublished: `isStaticPageUrl`; mrpam.gov.mn's guides reached the feed through a section hop) (the section hop had pulled such pages onto the home page as "today's" undated stories); undated stories never become the lead card; a day-level date 30+ days old that this source already gave 10+ articles becomes `date_unknown` (stray stamp) instead. `npm run db:repair-dates` (`--dry-run`) applied these rules to the old rows and deactivated constcourt.mn (→ `conscourt.gov.mn`), inspection, dundgovi, orkhon, naog with the reason in `last_error`.
- Sources rotate least-recently-scraped first under a time budget; failing sources back off 2^n hours, capped at `MAX_BACKOFF_H` (8; `backoffMs` in db-sink.ts; the old 64 h cap kept mof.gov.mn, mfa.gov.mn, customs.gov.mn and ulaanbaatar.mn silent for three days after one bad network minute on Oct 28 2026).
- `robots.ts` + `http.ts`: our own robots parser and 8s-per-host throttle for non-Crawlee fetches. `getRobots` retries a network error once after `ROBOTS_RETRY_MS` (3 s; a 5xx is not retried), and crawl.ts reads the robots.txt files `ROBOTS_CONCURRENCY` (8) at a time (`mapLimit`): a `Promise.all` over every source made ~40 sources fail in the same second on Oct 26 2026 with "robots.txt unreachable (ETIMEDOUT)" and start their backoff. The crawler uses the same `getRobots()` (not Crawlee's `respectRobotsTxtFile`, which treated an unreachable robots.txt as "allowed", refetched it before every request and ignored Crawl-delay): every queued request passes it (`add` in `runPass`), a refused listing fails like a failed request (`onFailure`, so home/feed fallbacks still apply), RFC 9309: 5xx or unreachable robots.txt = crawl nothing this run (`unavailable` says why in `last_error`). robots.txt is fetched with the page crawl's TLS stance (`robotsFetch`, got-scraping) so a broken .gov.mn certificate is not "unreachable"; the largest Crawl-delay (≤ 20 s) becomes the per-domain delay.
- Public destinations only (`net-guard.ts`, Oct 2026 security scan): publishers choose where our requests go (redirects, WordPress `link`, the advertised REST base, feed items), so `politeFetch` and `getRobots` use `publicFetch` (npm `undici` with `publicDispatcher`: a DNS lookup that refuses any private, loopback, link-local/metadata or CGNAT address, plus a check of IP-literal hosts, at connect time, so every redirect hop is covered and a DNS answer cannot change between check and use); Crawlee's HTTP pass and `robotsFetch` get the same lookup through `guardGotOptions` (HTTP/1.1, a `beforeRedirect` check), and the browser pass aborts requests to non-public hosts in its `page.route` (`isPublicHost`). The advertised WordPress base and a post's `link` count only on the source's own site, legalinfo.mn list links only on legalinfo.mn. Publisher input is processed in bounded time: robots wildcards use `matchesRobotsPattern` (no regex built from the file), `stripHeavyTags` stops after `MAX_STRIP_PASSES` (3), `parseFeed` reads each item's own children, the cheerio fallback reads each outermost block once, the amount and re-check filters have no overlapping repetitions, robots.txt is read up to `ROBOTS_MAX_BYTES` (500 KiB), a Crawl-delay counts up to `MAX_CRAWL_DELAY_MS` (20 s) everywhere, and the admin URL filter reads at most 5 MB (`readTextLimited`). `tests/scanner-findings.test.ts` pins each case. Text from outside printed to an Actions log goes through `oneLine()` (`src/lib/log-safe.ts`): a line break in a headline could start a `::error::` workflow command.
- Source health (`SourceRun` in `src/lib/scraper/source-run.ts`, one verdict for API and HTML sources: crawl.ts and `runApiSource` only report events): a source whose every article request failed (403, timeouts) is failing, not healthy, even when the listing also showed known items. An article URL whose HTTP extraction is the site's own title over menu text (a JavaScript shell) goes to the browser pass instead of being stored (sport.gov.mn had no published story); with `--no-browser` or a browser launch failure a JavaScript-only listing keeps its place (`SourceRun.browserUnavailable`). db-sink claims each content hash for the run before its check (two URLs of one page were both stored, #1379/#1380). `politeWait` reserves the per-domain slot before sleeping. API and feed headlines use `plainTitle` (whitespace only; `cleanTitle`'s "Site | Headline" split is for `<title>` and cut "Сайд Б.Бат - Хууль баталлаа" in half); an `og:site_name` equal to the headline is not taken as the site's name. robots.txt groups apply only when they name our product token whole (`IlTodBot`, optionally `/version`). `newestYearMentioned` ignores years after next year (targets like "2030 он хүртэл"). `safeDecode` never throws on a broken `%` escape. Time budget (Oct 29 2026): the HTTP pass gets `httpBudgetMs` = 70 % of `--budget` (`BROWSER_BUDGET_SHARE`), the browser pass the rest; before that the HTTP pass always ran out the whole 30 min (one site's robots.txt Crawl-delay 20 s was applied to all 122 domains through Crawlee's global `sameDomainDelaySecs`), the browser pass never started and 69 sources a run ended "not reached" with no health written, so mof.gov.mn's 404s were never recorded and JavaScript-only sites were never read. Now `sameDomainDelaySecs` stays at the 8 s floor and `politeWait` (a pre-navigation hook) adds each domain's own Crawl-delay (`domainDelayMs`, ≤ 20 s). When the browser pass still cannot run, only a JavaScript-only listing with no HTTP error and nothing stored keeps its place in line (`browserUnavailable`); everything else is recorded (`tests/source-run.test.ts`). Dates in the future (`isFutureDate`: a timed one > 1 h ahead, a day-level one after today in Ulaanbaatar) are dropped in the extractor and again in db-sink (feeds/APIs). `stripHeavyTags` is a linear scanner (a self-closing `<svg/>` used to swallow the article up to the next `</svg>`). `/posts/<id>` links are articles; only the bare `/posts` listing is not. "Site | Headline" titles keep the headline (with two parts the longer one).
- `net-setup.ts` (imported by `http.ts` and `crawl.ts`) raises Node's per-address connect attempt from 250 ms to 3 s: from GitHub's US runners .gov.mn is ~250-300 ms away and 57 sources failed at once with an empty `AggregateError [ETIMEDOUT]`. `errorMessage()` reports the error code when the message is empty.
