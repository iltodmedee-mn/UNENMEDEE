# History

What each audit and incident changed and why, one bullet per PR, newest last. The rules themselves live in `docs/agents/`. Append new bullets at the end (this file merges with `merge=union`).

- Audit #5 PR A (Nov 2026, what readers see is true): an admin edit of the title drops `reader_title` (readers see `coalesce(reader_title, title)`, so a corrected title stayed hidden) and the editor's "clearReader" box drops `reader_impact` too; `getDigestById` (the /ig-image card) and `getDigests` drop withdrawn stories and an edition with none left; `getClusters` returns only clusters with ≥ 2 distinct published sources (over-fetched ×2); `getArchiveDays` counts from the Ulaanbaatar midnight `days` back, not a rolling timestamp; /request takes today from the browser once hydrated (`useSyncExternalStore`, server snapshot = the cached day); `/story-image` checks own keys (`Object.hasOwn`: `?p=constructor` crashed), `/source/<bad %>` is a 404; the topic bar has `budget` and `ministry` chips. `MONTH_LABEL` reads a two-digit day whole ("11-р сарын 15" was day 5) and `dateFromText` takes the first *valid* match of each pattern (a future event date no longer leaves the story undated); `numbersGrounded` compares a number with a scale word by value ("15 тэрбум" is not grounded by "15 сая"); `shouldResynthesize(prev, new, hasSynthesis)` fires when any milestone lies in (prev, new] or the cluster has no synthesis yet (a cluster born with 4 members waited for 5). Model- or publisher-written text printed to the Actions log (`attempts`, digest fallbacks, make-digest headlines, press-feed errors) goes through `oneLine`/`errorLine`.
- Audit #5 PR B (scraper and pipeline robustness): API detail pages (`runApiSource` in run-scraper.ts) are read one by one with their own try/catch: an HTTP error (the adapters now throw on `!page.ok`) is counted and the source fails only when every page failed and nothing was stored (one 30 s portal timeout used to discard the source and start its backoff after it had stored stories); a page with no article text (photo posts) is `markNoText` → `seen_urls` with `content_hash = NO_TEXT_HASH` ("no-text"), so it is never fetched again; the per-source limit counts stories read, not pages tried. The weekly re-check skips the rest of a host after `MAX_HOST_ERRORS` (3) fetch errors in a row (a dead host's rows keep a null `source_checked_at`, stay first in line and held a worker for the whole run). API, feed and story-page bodies are read through `readJsonLimited` / `readTextLimited` (`API_MAX_BYTES` 5 MB; only the admin URL filter was bounded). Router: a call that returned no tokens (429, timeout) still counts against `<PROVIDER>_DAILY_MAX_CALLS` in memory (OpenRouter's 50/day account quota was spent on 429s our counter never saw). The "another $0 provider next in line" test after a 429 stays on the price table on purpose: Requesty's default model is free and the router should move to it at once (`tests/limits.test.ts`).
- Audit #5 PR C (social, video, civic data, ops): the tender sync reads months oldest first so the NEWER filing wins in `mergeLot` (a corrected contract or winner lost to the older month) and the upsert computes `unit_suspect` from the merged budget and contract in SQL (`MIN_PLAIN_MNT`, `UNIT_RATIO` exported);
