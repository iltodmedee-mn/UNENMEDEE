API, feed and story-page bodies are read through `readJsonLimited` / `readTextLimited` (`API_MAX_BYTES` 5 MB; only the admin URL filter was bounded). Router: a call that returned no tokens (429, timeout) still counts against `<PROVIDER>_DAILY_MAX_CALLS` in memory (OpenRouter's 50/day account quota was spent on 429s our counter never saw). The "another $0 provider next in line" test after a 429 stays on the price table on purpose: Requesty's default model is free and the router should move to it at once (`tests/limits.test.ts`).
