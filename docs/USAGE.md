## 11/22: Hobby руу шилжих оролдлого, сургамж

1. **Hobby нь GitHub organization-ий repo-оос deploy хийдэггүй.** Манай репо `iltodmedee-mn`-д байгаа тул deploy-г GitHub Actions (`vercel build` + `vercel deploy --prebuilt`) руу шилжүүлсэн (#326).
2. **`vercel pull` «Sensitive» утгыг татдаггүй.** `DATABASE_URL` зэрэг 7 утга `"[SENSITIVE]"` болж ирсэн тул анхны deploy хоосон хуудастай гарсан (~14 минут, 03:21–03:35 UTC). Засвар: build-д `DATABASE_URL`-ийг GitHub secret-ээс авах (#327).
3. **Usage-ийг эхэлж шалгах ёстой байсан.** Downgrade-ийн дараа л 30 хоногийн хэрэглээ Hobby-ийн 4 хязгаараас хэтэрсэн нь харагдсан. Мөн өдөр Pro руу буцаж, Git deploy-г сэргээсэн (#328). Pro-гийн ашиглаагүй хоногийн $9.64 карт руу буцаж орсон (Vercel credit биш).
4. Дахин Hobby руу шилжихээс өмнө: Usage-ийн бүх мөрийг Hobby-ийн хязгаартай тулгах, 2 долоо хоног хязгаараас доош байхыг харах, дараа нь deploy-г Actions руу шилжүүлэх (#326/#327-ийн кодыг git түүхээс сэргээж болно).

## Судалсан бусад сонголт

- **Cloudflare Pages (статик):** цаг бүрийн бүтэн build бүх өгөгдлийг DB-ээс уншина (Supabase egress), үнэгүй багцад сард 500 build, сайт 20 000 файлаас хэтрэхгүй, хайлт / reaction / push / admin / API ажиллахгүй. Тохирохгүй.
- **VPS (Tokyo / Seoul / Singapore):** манай хэрэглээнд 2 vCPU, 4 GB хангалттай. Ойролцоо үнэ (11/22, гуравдагч сайтаас, баталгаажуулаагүй): Oracle Cloud Free (ARM, сул сервер олдох нь ховор) $0, Contabo Tokyo 4 vCPU/8 GB ~€8, UpCloud Tokyo 2/4 GB ~€12, Vultr ба Lightsail 2/4 GB $20–24. Шилжвэл HTTPS, дахин асаалт, шинэчлэлт, CDN-ийг өөрсдөө хариуцна. Vercel дээрх багасгалт хангалтгүй бол л авч үзнэ.
